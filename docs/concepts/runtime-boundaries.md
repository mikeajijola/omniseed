# Runtime boundaries

```text
Omniform definition → OmniSeed Core → runtime operations/transport → OmniSeed OS
```

Omniform defines meaning. Core validates and calculates; providers translate plans to implementations; runtime operations expose a stable capability boundary; OmniSeed OS consumes these outputs. Desired configuration never becomes state. Planning never becomes approval. AI may interpret unstructured evidence but cannot replace schema checks, graph traversal, diffs, permission checks, or bookkeeping.
